# Python Tuples for Beginners

This project has small Python programs to help you learn about tuples.

A tuple stores multiple values in one variable. Write its values inside
parentheses, separated by commas:

```python
fruits = ("apple", "banana", "cherry")
```

The example files show empty tuples, numbers, words, mixed values, and how to
make a tuple with one item. Open a file to see its code.

## Run an example

1. Open a terminal in this folder.
2. Run a file with Python. For example:

   ```bash
   python 1.py
   ```

Change `1.py` to another example filename to try a different program.
